# Reports

The **AI Global Deployment Insights** deliverables (Markdown, DOCX, figures, Pandoc templates, scripts) now live in a dedicated folder **outside** this repository:

**`~/AI_Atlas_Report`** (or `$HOME/AI_Atlas_Report`)

Regenerate the Word report from there:

```bash
cd ~/AI_Atlas_Report
./build_docx.sh
```

If your report folder lives elsewhere, point `cd` at that directory instead.
